Encapsulation

Simple Explanation: Bundling data and methods inside a class while hiding internal state using private fields (#). External code cannot corrupt data directly; it must go through validated getters and setters. 

class Task extends BaseRecord {
  #title;      // Private field
  #priority;   // Protected state

  set title(value) {
    if (!value || value.trim().length < 2) {
      throw new Error("Invalid task title");
    }
    this.#title = value.trim();
  }
  get title() { return this.#title; }
}
2

Inheritance

Simple Explanation: Child classes (Task, Subject, StudySchedule, StudyNote) inherit common properties like #id, #createdAt, and touch() from the parent BaseRecord class using extends and super(). 

class StudyNote extends BaseRecord {
  #content;
  constructor(data) {
    super(data); // Calls BaseRecord constructor
    this.#content = data.content || "";
  }
}

Polymorphism

Simple Explanation: Different child classes override the exact same method name (getSummary() and validate()) to produce tailored behavior when called uniformly in loops. 

// Same method call, different runtime behavior:
records.forEach(record => {
  console.log(record.getSummary());
});
// Task -> "[High] Complete Lab (Due: 2026-11-28)"
// Note -> "Note: OOP Lecture (142 chars)"

Abstraction

Simple Explanation: Hiding complex implementation details behind clean interfaces. BaseRecord prevents direct instantiation (new.target === BaseRecord) and enforces abstract contracts, while StorageRepository hides JSON & localStorage mechanics. 

class BaseRecord {
  constructor() {
    if (new.target === BaseRecord) {
      throw new Error("Cannot instantiate abstract class!");
    }
  }
  getSummary() { throw new Error("Must override!"); }
}
